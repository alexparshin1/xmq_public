# Mosquitto import corpus

Rules copied from Mosquitto's own examples and test suite, kept as they are so the importer is
tested against real input rather than only against strings written in the test file.

| File | Source |
| --- | --- |
| `aclfile-example.acl` | [`aclfile.example`](https://github.com/eclipse-mosquitto/mosquitto/blob/master/aclfile.example) at the repository root |
| `acl-access-variants.acl` | `write_acl()` in [`test/broker/09-acl-access-variants.py`](https://github.com/eclipse-mosquitto/mosquitto/blob/master/test/broker/09-acl-access-variants.py) |
| `acl-change.acl` | `write_acl()` in [`test/broker/09-acl-change.py`](https://github.com/eclipse-mosquitto/mosquitto/blob/master/test/broker/09-acl-change.py) |
| `acl-empty.acl` | `write_acl()` in [`test/broker/09-acl-empty-file.py`](https://github.com/eclipse-mosquitto/mosquitto/blob/master/test/broker/09-acl-empty-file.py) |
| `acl-persist-deny.acl` | The deny phase of [`test/broker/15-persist-client-msg-modify-acl.py`](https://github.com/eclipse-mosquitto/mosquitto/blob/master/test/broker/15-persist-client-msg-modify-acl.py) |
| `dynamic-security-init.json` | [`test/broker/dynamic-security-init.json`](https://github.com/eclipse-mosquitto/mosquitto/blob/master/test/broker/dynamic-security-init.json), generated by `mosquitto_ctrl dynsec init`; its password is a test credential |
| `dynamic-security-priorities.json` | Written here from the priorities example in the [Dynamic Security documentation](https://mosquitto.org/documentation/dynamic-security/), with a direct role, two groups of different priority and ACLs of different priority |
| `acl-mixed-patterns.acl` | Written here, following the `%u`/`%c` patterns documented for `acl_file` |

`SettingsTests/MosquittoImportCorpusTests.cpp` parses every file in this directory, so a file added
here without a test still gets imported by the suite. The tests then check the cases that matter:
anonymous rules not reaching named clients, deny before allow, patterns expanded with the username
and client id at check time, temporary empty files, and Mosquitto's role/group priority order.
