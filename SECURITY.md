# Security policy

## Supported versions

Public security fixes are provided for the latest published XMQ release only.
When a newer release is published, earlier releases leave public security support.
Support for an older version may be arranged under a separate commercial support
contract. To discuss a contract, contact <alexeyp@gmail.com>.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through this repository's
**Security → Advisories → Report a vulnerability** form on GitHub. Do not put
undisclosed vulnerability details in a public issue or pull request. If the
GitHub form is unavailable to you, email <alexeyp@gmail.com> instead.

Include the affected XMQ version, the conditions needed to reproduce the issue,
the expected security impact, and reproduction steps or a proof of concept if
available. Remove passwords, tokens, private keys, and personal data from logs
before sharing them.

The maintainers will review the report, ask for more information if needed, and
coordinate a fix and disclosure with the reporter. Once a fix is released, they
can publish a GitHub security advisory describing the affected and fixed versions.
