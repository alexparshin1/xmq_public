XMQ 1.0.2 focuses on cluster administration, bounded queues, and reliable message delivery. You can download it here.

  • Nodes join clusters directly: the obsolete invitation workflow is removed, while authenticated remote Start, Join, Leave, and Retire actions remain available.
  • Cluster settings stay with the node in the shared database: listener and web-service changes are saved there and take effect without a broker restart.
  • Queue limits now bound the whole client session: message and byte limits include in-flight deliveries as well as messages waiting behind them.
  • Reconnects and session handovers are more reliable: fixes prevent a reconnect from losing its live connection and preserve delivery as a persistent session moves between nodes.
  • Rejected publications are visible in monitoring: the $SYS/broker/messages/publish/dropped counter now reports messages refused by queue limits.
