# event_logger

An XMQ extension, generated by `new-extension.py`.

## Build it

```sh
cmake -B build .
cmake --build build
```

That works before you write anything: the skeleton compiles, loads, and logs that it started. Get
that far first - it separates "my code is wrong" from "my build is wrong", and the second is much
harder to see.

## Let the broker load it

Copy `libxmq_event_logger.so` somewhere the broker can read - **not** `lib/xmq`, which is served over
HTTP to anyone who can reach the configuration interface. `lib/xmq-extensions` is the usual place.

Then add the entry in `event_logger.conf.json` to `xmq_extensions.conf`, beside `xmq_server.conf`. The
broker has no such file until you make one, which is not an error - it just means no extensions.

Restart the broker. It logs the name and version of everything it loaded, and says why for anything
it did not.

## What to write, and where

Every decision left to you is a `TODO` in `EventLogger.cpp`, next to a comment saying what the choice
is between. Start with `start()`.

## The three rules

1. **Include and link nothing of the broker.** The ABI header is the whole contract, and it is what
   lets this survive a broker upgrade and be built with another compiler.
2. **Declare only the capabilities you implement.** With one undeclared, the broker never builds the
   machinery behind it, and the path it would have sat on keeps its original shape.
3. **Do not block the broker.** `authenticate()` and `resolveGroup()` run on a pool of their own and
   may block; `onEvent()` runs on the host's thread behind a bounded queue and may take its time;
   `authorize()` is awaited by a connection and must not block.

## When it does not load

The broker's log says which. The usual causes, in the order they happen:

- *"exports no xmq_extension_describe"* - the entry point was hidden by `-fvisibility=hidden`.
  `XMQ_DEFINE_EXTENSION` applies `XMQ_EXTENSION_EXPORT` for you, so this means the macro is missing
  or is not at namespace scope.
- *"the library calls itself X"* - the name in `XMQ_DEFINE_EXTENSION` and the `name` in the
  configuration must be the same string.
- *declined* - the library was built against a newer ABI than this broker's.
